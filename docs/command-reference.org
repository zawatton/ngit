=bin/ngit= passes each argument with an "@" prefix because the NeLisp
runtime drops =-q=, =-Q=, =--batch= and =--no-init-file= even after =--=.

=NGIT_NELISP= selects the runtime binary (default =nelisp= on PATH) and
=NGIT_NELISP_ROOT= the NeLisp checkout providing =packages/nl-ffi=
(default: =../nelisp= next to this repository).

Status, diff, add and restore accept literal paths relative to the invocation
directory, including repeated =-C=. Human status paths follow
=status.relativePaths=; porcelain status and default diff paths remain
relative to the work-tree root. Diff path arguments require =--=.

Log, show, grep, blame and ls-tree also resolve literal path arguments from
the invocation directory. Log keeps its existing glob support and remains
repository-wide without paths; grep defaults to the invocation subtree.
Blame's porcelain paths and history diff paths remain root-relative.
Ls-tree's =--full-name= changes displayed names; =--full-tree= also selects
from the tree root. Ordinary =REV:path= object names remain tree-relative,
while =REV:./path= and =REV:../path= use the invocation directory.

Status, diff, add, restore, log and grep share =top=, =literal=, =glob=,
=icase= and =exclude= pathspec magic. Ls-tree accepts =top= and =literal=
and rejects unsupported magic. Literal filename arguments to show and blame
retain their existing interpretation.

Push supports explicit and tracking-based =--force-with-lease= expectations
and receive-pack =--atomic= negotiation over local/file/SSH and smart HTTP(S)
transports. As in the Git 2.47.3 comparison oracle, explicit =--force= or a
forced refspec overrides a lease. =--atomic= fails if the peer does not
advertise the capability.

Fetch, clone, pull and ls-remote speak Git protocol v2 by default
(=protocol.version= 0, 1 or 2, as Git), with =ref-prefix= ls-refs requests,
Git's default negotiator (stateful over file/ssh, stateless over HTTP) and
=-o=/=--server-option=; push stays on protocol v0, as in Git.
Smart HTTP(S) uses libcurl for streamed discovery and RPCs, one POST per
protocol-v2 command or negotiation round.
HTTPS verifies the peer and hostname; =GIT_SSL_CAINFO= or =http.sslCAInfo=
can supply a private CA. Explicit Basic URL credentials and =http.extraHeader=
are supported. Discovery redirects are bounded and drop credentials and
custom headers when the origin changes; RPCs are never redirected or retried.
Discovery redirects currently omit Git's redirect warning on stderr.

Noninteractive Basic authentication supports ordered =credential.helper=
get/store/erase chains, empty-value resets, URL-scoped settings and
=credential.useHttpPath=. Helpers may use shell snippets, absolute commands,
or names available through =PATH= or explicit =GIT_EXEC_PATH=. Exchanges have
bounded input, output and deadlines; interactive prompts and OAuth flows
are not implemented. A discovery challenge can trigger one authenticated
GET retry; a POST is never replayed.

Configuration expands =include.path= and =includeIf= conditions for =gitdir:=,
=gitdir/i:= and =onbranch:= at their source positions. Relative paths resolve
against the including file. Selected =config --file=, =--local= and =--global=
reads follow includes only with =--includes=; writes affect the selected
primary file. =hasconfig:remote.*.url:= conditions match against the
remote URLs of the whole configuration, and a file they include may not
define remote URLs itself (Git's fatal error).

Status and diff detect modified renames with the shared similarity detector.
Diff accepts fractional or percent =-M= / =--find-renames== thresholds and
=diff.renameLimit=; status honors =status.renames= and =status.renameLimit=.
Inspection uses work-tree bytes without storing new blob objects.

Directory rename inference follows =merge.directoryRenames= for merge,
cherry-pick, revert and stash application. Relocation conflicts preserve
side contents and the operation's continue/abort state.

Clone, fetch and pull use a Linux/Python 3 process supervisor with an
8192 MiB aggregate memory budget. Set =NGIT_MEMORY_BUDGET_MIB= to a positive
integer to change it; setting it also enables supervision for other commands.
The supervisor samples the process tree and its own PSS every 50 ms, using
summed RSS as a conservative upper bound when PSS is unavailable. Exceeding
the budget terminates the owned tree. Sampling permits allocation overshoot;
this is not a hard allocation ceiling. Worker counts and received-pack caches
also adapt to the budget. Ordinary commands keep their direct startup path
when the variable is unset.
