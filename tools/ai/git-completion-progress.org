#+TITLE: ngit completion: nearly all major git commands (stages 7-11)

Completion target chosen on 2026-10-19: nearly all major git commands.
Stages 1-6 are measured by their own ledgers in this directory; this
ledger covers what remains.  Scope decisions made with the user:
- Transports are file:// (and local paths) and ssh (spawning ssh, as git
  does).  https is out of scope (TLS is outside the compression-only FFI rule).
- Hooks are in scope.
- The submodule command is out of scope (gitlinks are already read and
  written).
- Anything needing an editor or a TTY (rebase -i, add -p, commit without
  -m/-F) and signing stay out of scope.
Commands that write packs (gc, repack, push, fetch, clone) cannot be
byte-identical to git because delta selection differs; their criteria
compare refs, reflogs, the reachable object set (rev-list --all --objects)
and a clean git fsck instead of pack bytes.
Each criterion's suite or mode is added with the work; until then
compare.sh and the real-* scripts exit 2 for the unknown name.
