#+TITLE: ngit HTTPS, pathspec and directory-rename compatibility

Baseline: 8eb1cd5. Three isolated lanes implement smart HTTP(S), common
top/literal/glob/icase/exclude pathspecs in selected consumers, and directory
rename inference. Protocol v2, dumb HTTP, shallow/partial clone, credential
helper integration, sparse indexes and interactive operations are outside
this slice. The fifteen criteria are defined before implementation.
