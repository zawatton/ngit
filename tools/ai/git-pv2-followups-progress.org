#+TITLE: ngit protocol v2 follow-ups

Baseline: 5db0c7f.  The follow-ups recorded when protocol v2 was committed
(worklog "ngit fetch-side protocol v2 committed (5db0c7f)"): launcher memory
supervision with global options, file:// protocol v1 diagnostics, HTTP bytes
after the final flush, rejected-delete push output, and three gaps in
test/protocol-v2.py (Content-Length values, --set-upstream configuration, no
local-path or file:// cases).  Eight criteria were defined before
implementation; S1.5 was added after the independent review and narrowed
after the second one: the config-case cases for --replace-all/--unset-all and
value patterns on differently spelled variables, unimplemented global options,
and --git-dir/--work-tree/--bare with status fail at 5db0c7f as well; they are
kept ungraded in the config-deferred mode and listed in README.  S2.1 was split into S2.1
and S2.4 (same suites) because the pull suites alone take up to 530 s and did
not fit the 600 s limit beside the others on a loaded machine.

Each suite reports exact comparisons and intended differences separately.
An intended difference is a named diagnostic or security divergence with a
reason recorded in the suite; it never counts as an exact comparison.  The
verifier enforces a floor of exact comparisons per mode.
